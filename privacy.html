JARVIS Backup - Privacy Policy

Last updated: November 17, 2026

1. Purpose

JARVIS Backup is a private utility intended for personal data backup and recovery by its authorized owner.

2. Google Drive Access

The application uses the Google Drive API with the drive.file permission to create, access, update and delete files managed through the application's authorization.

3. Data Processing

When cloud backup is enabled, the utility processes backup archives and associated file metadata for storage and recovery. Backup contents may include personal information selected by the owner.

4. Encryption and Security

The intended backup process encrypts archives locally before uploading them to Google Drive. Encryption keys and account credentials are intended to remain outside cloud backup storage.

5. Data Sharing

Backup archives are stored using Google Drive. Data is not sold or shared for advertising purposes.

6. Data Retention and Deletion

The owner controls backup retention and can delete stored archives. Google Drive authorization can be revoked through Google Account settings.

7. Public Website

This website provides information about the backup application. It does not provide public access to backup files. Hosting services may process standard technical access logs.

8. Contact

Questions about this application can be submitted through its GitHub project page .
